“Los días de escribir código a mano están llegando a su fin.”

Original: "The days of writing code by hand are coming to an end." Meijer dedicó su vida a hacer más fácil escribir código. Que él diga esto no es marketing. Frase hermana: "We are going to be the last generation of developers to write code by hand, so let's have fun doing it." Kim & Yegge abren Vibe Coding con esta cita — anchor narrativo del libro. Ritmo: leer, pausa larga, pasar sin comentar.
