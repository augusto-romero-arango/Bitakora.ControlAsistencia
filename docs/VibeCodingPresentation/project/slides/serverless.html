Serverless

El código es un pasivo

Cada línea que se escribe se mantiene, se defiende y se paga.

El cloud opera lo que no queremos operar: servidores, parches, capacidad, escalado.

Se paga por uso real — no por capacidad reservada.

Menos código propio: menos bugs, menos deuda, menos riesgo.

“Un enfoque serverless-first asegura carga operativa baja y ciclos de retroalimentación rápidos.” — Anderson, McCann, O'Reilly · The Value Flywheel Effect, 2022

Conecta con la IA: los agentes escriben código a volumen; si el código es pasivo, hay que ser deliberados. Sirve de puente al slide de IaC.
