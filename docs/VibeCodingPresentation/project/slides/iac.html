Infrastructure as Code

Clickops no escala, no se automatiza

La infraestructura se declara en código, se revisa en PR, se despliega por pipeline.

Clickops son pasos manuales que ningún pipeline puede reproducir.

El agente lee y modifica configuración declarativa; el portal gráfico lo deja ciego.

Clickops rompe la cadena automatización -> repetibilidad; la IA no navega portales gráficos. En la pasada se amplía: HCL = HashiCorp Configuration Language, el lenguaje declarativo de Terraform para describir recursos en la nube. Junto con serverless habilitan que un agente levante un dominio completo (infraestructura + código) desde un prompt hasta producción.
