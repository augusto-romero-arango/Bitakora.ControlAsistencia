Event Sourcing

La historia es la verdad

Se guarda lo que pasó.

El esquema evoluciona sin tumbar nada.

El agente reconstruye el porqué.

La auditoría es el sustrato.

La verdad vive en los eventos (append-only). El estado se proyecta desde ahí. Persistencia sin migraciones traumáticas; historia completa para IA y para trazabilidad legal. Marten solo se menciona en la pasada, no aparece en el slide. Cambios de diseño = nuevas proyecciones, no ALTER TABLE con downtime. El historial completo es contexto para el agente. Cuando un incidente pasa, el agente puede reconstruir qué pasó y cuándo.
