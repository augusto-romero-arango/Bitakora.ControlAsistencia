El acrónimo con el que Kim y Yegge describen el beneficio del vibe coding bien hecho.

FAAFO desplaza a "debugging" como loop mental dominante. Antes se preguntaba "¿cómo encuentro el bug?"; ahora se pregunta "¿qué tan rápido puedo iterar entre FAAFO?". Ambitious: atacar problemas que antes no se intentaban. Autonomous: delegar al agente con supervisión ligera. Optionality: probar 3 caminos donde antes solo se podía probar 1. Fuente: libro Vibe Coding + review de Mike Hadlow.
