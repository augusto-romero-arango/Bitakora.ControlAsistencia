## Contexto
Tercer issue partido de #1323: la tool `obtener_plantilla` deja de anteponer el nombre del turno, apoyada en las marcas de descanso y horario abierto de #1325.

## Descubrimientos
- Con #1325 el endpoint siempre devuelve `esDescanso`/`horarioAbierto`: un cuadro viejo sin marcas es indistinguible de un turno normal, asi que muestra su `descripcion` tal cual.
- La misma tool ya exponia el id de la Jornada: precedente para exponer el id del turno.

## Decisiones
- Cada dia expone `turnoId` (decision del usuario), omitido en dia vacio y turno retirado, conservado en incompleto.
- Textos: descanso -> `descanso`; abierto -> `horario abierto de {duracion}`; franjas -> descripcion; retirado/incompleto/sin turno sin cambios.
- #1326 pasa a estado:listo (sigue bloqueado por #1325).

## Descartado
- No exponer el id y cruzar el horario con `buscar_turnos` (ambiguo si dos turnos comparten horario).
