## Contexto
El run 34722573915 (Deploy Sedes, SHA bf0e7c1) fallo en smoke-tests: "/api/version no reporto el SHA esperado en 120s". Se investigo con logs del job, Kudu (deployment log, docker log, StartupLogs) y App Insights.

## Descubrimientos
- El deploy fue sano (ZipDeploy OK 22:26:06Z). El contenedor nuevo aborto al arrancar: host de Functions con "Unhandled exception. System.AggregateException (A task was canceled)" en Program.Main, exit code 134, "Site startup probe failed after 128.5s". Cero telemetria de esa instancia: el worker .NET nunca arranco.
- Mientras el nuevo no pasaba el warmup probe, el contenedor viejo siguio sirviendo /api/version con el SHA anterior: el gate no distingue swap lento de contenedor abortado.
- La plataforma reintento sola ~90 s despues; el mismo paquete subio en 44 s. Sedes estuvo caido 22:29:04-22:31:26Z.
- Es recurrente: LastErrorDetails registra exit code 134 en Sedes (2026-09-01, 149.9 s) y ControlHoras (2026-08-30). Swaps sanos de hoy: 44/52/76/92 s, cerca de los 120 s del gate.
- Observacion sin verificar: WEBSITE_USE_PLACEHOLDER_DOTNETISOLATED=1 en planes B1 (la doc lo describe para Consumption). Sin App Service logs (stdout) habilitados, el crash solo deja StartupLogs.
- Fuentes de evidencia utiles para futuras investigaciones: Kudu /api/vfs/LogFiles/StartupLogs/*_failure.log y *_docker.log via token ARM.

## Decisiones
- Rerun del job fallido (gh run rerun --failed): Version OK al primer intento, suite smoke Passed. Deploy bf0e7c1 verificado.
- Issues borrador: #674 (tooling, gate de smoke tests que detecte ContainerStartupFailure / cubra un ciclo de reintento) y #675 (infra, revisar WEBSITE_USE_PLACEHOLDER_DOTNETISOLATED y capturar stdout del contenedor).

## Descartado
- Relanzar el deploy completo: innecesario, el paquete ya estaba desplegado.

## Preguntas abiertas
- Causa interna del TaskCanceledException del host: no determinable sin stdout del contenedor. Hipotesis: MSI sidecar (AzureWebJobsStorage por identidad), share /home, flag de placeholder.
- Trafico TEST-* contra Sedes a las 22:32Z sin run de GitHub asociado: probablemente ejecucion local de la suite.
