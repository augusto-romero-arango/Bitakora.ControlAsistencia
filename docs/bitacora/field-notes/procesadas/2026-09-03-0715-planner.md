## Contexto
Los smoke de Comandos quedaron rojos tras el merge de #574 (registrar_colaborador rechaza "2026-09-01"), y Consultas estaba roto en vivo para toda fecha. El borrador #586 traia causa raiz y un helper por tool; se refino a listo.

## Descubrimientos
- Causa raiz verificada en upstream (tag worker-1.6.0 y main): DictionaryStringObjectJsonConverter.ReadString coerciona todo string a DateTimeOffset/Guid; McpInputConversionHelper cae en Convert.ToString para destino string (DateTimeOffset/Guid no son IConvertible). El DLL instalado contiene los cuatro tipos.
- Tercera tool afectada que el borrador omitio: consultar_programacion (desde/hasta). Su smoke y el de listar_colaboradores solo ejercen el camino invalido o el sin fecha: ese gap oculto el bug.
- El JSON crudo de la invocacion vive en FunctionContext.BindingContext.BindingData[<param trigger>] con los argumentos verbatim (host: Arguments = Request.Arguments como JsonElement). FunctionsMcpContextMiddleware lo deserializa a Items["ToolInvocationContext"]; ToolInvocationArgumentTypeConverter bindea desde ahi. Un middleware propio registrado tras ConfigureFunctionsWebApplication() corre despues y antes del binding.
- ToolInvocationContext SI es instanciable en tests (publica, init props); el comentario de IdentidadTenantMcpMiddlewareTests que dice lo contrario esta desactualizado.

## Decisiones
- Alcance ampliado: tres tools + GUIDs (decision del experto), lo que descarta el helper sobre context.Arguments (ya es Guid, sin texto). Diseno: ArgumentosCrudosMcpMiddleware por servidor (duplicado, Rule of Three 2a aparicion) que relee el JSON crudo y reemplaza Items["ToolInvocationContext"] restaurando hojas string; cero cambios en las tools; fail-open si faltan piezas.
- No se abre issue upstream en Azure (decision del experto); el codigo enlaza #129.
- Labels: tipo:refactor + bug + dom:colaboradores, control-horas, programacion, sedes (union de dominios cuyas Functions consumen las tools cubiertas). estado:listo.
- CAs: 6 en un solo eje (3 smoke, 1 unit del nucleo, error paths intactos, contrato sin cambios). Smoke: consultar_programacion gana su primera tool call valida (MEF-ADR-0048 s.2 v3).

## Descartado
- Helper por tool (context.Arguments o FunctionContext), parametro DateTimeOffset/object, regex, downgrade, issue upstream nuevo.
